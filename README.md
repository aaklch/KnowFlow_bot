# Цифровой ассистент для онбординга (минимальная версия)

## Запуск
1. Создайте бота у @BotFather, получите токен. Свой Telegram ID узнайте у @userinfobot.
2. Установите зависимости: `pip install -r requirements.txt` (нужен Python 3.9+).
3. Задайте переменные и запустите:
   - Windows (PowerShell): `$env:BOT_TOKEN="токен"; $env:MENTOR_ID="ваш_id"; python bot.py`
   - Linux/macOS: `BOT_TOKEN=токен MENTOR_ID=ваш_id python bot.py`
4. База `onboarding.db` создаётся и наполняется демо-данными автоматически.

## Для скриншотов
- /start, затем «❓ Спросить»: «как подключиться к VPN?», «где лежит документация», «как оформить отпуск».
- «📋 Мой план», нажмите «Выполнено» у пары шагов, затем /remind.
- Вопрос без ответа: «какой размер премии?» (уйдёт в gaps, наставнику придёт уведомление).
- /stats и /gaps с аккаунта наставника (MENTOR_ID).

## Замена данных
Статьи и шаги задаются в начале db.py (ARTICLES, STEPS). После правки удалите onboarding.db и перезапустите бот.
